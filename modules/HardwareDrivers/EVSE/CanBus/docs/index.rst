*******************************************
CanBus
*******************************************

:ref:`Link <everest_modules_CanBus>` to the module's reference.
Generic CAN bus interface module for EVSE communication. Provides raw CAN frame transmit/receive functionality based on Linux SocketCAN. Intended to be used by higher-level protocol modules such as GB/T 27930 DC, CHAdeMO, or diagnostic services.
